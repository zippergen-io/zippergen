# Parallel proof foundation

This directory is the reusable copy of the checked Lean development from
`paper-parallel/Lean/ZipperGenParallel`, imported at commit
`a8a625fe871d58a42bfe827ac96f6644d5ac40e0`.

The paper repository remains the frozen publication artifact. Changes needed
by ZipperGen's reusable proof machinery should be made here and deliberately
backported when a paper artifact needs to be refreshed.
