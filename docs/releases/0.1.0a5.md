This alpha makes local model setup easier and gives coding agents more precise
workflow and connector instructions.

- Guided local model setup shows the server URL, lists available models and
  offers participant assignment. Connection errors explain where the server
  or SSH tunnel needs to run. Fully specified configuration commands remain
  offline.
- The workflow skill now includes Gmail, Google Sheets, Google Calendar and
  Telegram helper signatures and return shapes, loop initialization guidance,
  and a runnable crash-recovery example using fake services.
- The manual covers the updated setup flow and remote model connections. The
  first tutorial prompt stays on one page and is easier to copy.

To upgrade after this version is available on PyPI:

```sh
uv tool install --upgrade "zippergen[google]==0.1.0a5"
```

Omit `[google]` if you do not use Google connectors. In an existing coding-agent
conversation, run `zg skill` again after upgrading.

Workflow syntax, the durable-store schema and deployment command meanings are
unchanged from 0.1.0a4. No state reset is needed for this package update.
Existing deployments keep their managed runtime until redeployed. Stop the
deployment and run `zg deploy` to apply the update while preserving compatible
saved state.

ZipperGen is still an alpha. Workflows and deployment setup are trusted Python
code. Assistant environment filtering does not isolate credential files
readable by the same operating-system account. External effects can repeat
after a crash unless the external service supports idempotency. See the
[security notes](https://github.com/zippergen-io/zippergen/blob/v0.1.0a5/docs/security.md).
